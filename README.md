## Current Research

### RO-OBMP2

I am currently working on the development and implementation of a Restricted Open-Shell Orbital-Optimized Second-Order Many-Body Perturbation Theory (RO-OBMP2) method for open-shell electronic systems.

The project involves:

- Restricted open-shell references
- Many-body perturbation theory
- Orbital optimization
- Baker–Campbell–Hausdorff expansions
- Open-shell spin treatment
- Electronic-structure implementation and benchmarking

[RO-OBMP2 repository →](https://github.com/vchucphong1208/ro-obmp2)
